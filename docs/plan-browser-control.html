1. Overview & Goals

Problem Statement

Playwright provides headless browser automation but cannot access personal browser sessions (cookies, logins). We need a solution that lets Eliezer control the user's actual Chrome/Firefox browser remotely.

Solution

A Chrome/Firefox extension that connects to the Clawchat server via SSE + REST (the proven pattern used by the web app). This gives Eliezer full control of the user's browser with their explicit permission.

Key Principle: Reuse existing infrastructure. The web app already proves SSE + REST works bidirectionally without WebSockets. No new protocols needed.

4. Communication Protocol

Direction 1: Server → Extension (Commands)

Extension opens SSE connection to receive commands from Eliezer.

GET /api/browser/events
SSE stream for receiving commands. Extension connects and maintains persistent connection.
// Server sends command via SSE event: command data: { "id": "cmd-uuid-123", "action": "navigate", "params": { "url": "https://linkedin.com" }, "timestamp": 1708000000000 }

Direction 2: Extension → Server (Results)

Extension POSTs results after executing commands.

POST /api/browser/response
Submit command result after execution
// Extension POSTs result { "commandId": "cmd-uuid-123", "status": "success", "result": { "title": "LinkedIn", "url": "https://www.linkedin.com/feed", "loadTime": 1200 }, "timestamp": 1708000005000 }

Direction 3: Extension → Server (State)

Extension periodically reports current page state.

POST /api/browser/state
Periodic heartbeat with current browser state
// Heartbeat every 5 seconds { "sessionId": "ext-session-456", "connected": true, "currentUrl": "https://example.com", "pageTitle": "Example Domain", "ready": true, "timestamp": 1708000010000 }

Direction 4: Server → Eliezer (Response Delivery)

Clawchat receives the extension's response POST and pushes a browser:response event to Eliezer's event queue (POST /events). The tool resolves its promise when the matching event arrives. 30s timeout.

5. Security Model

Principle: User maintains full control. Remote access is opt-in per session.

Authentication

Extension authenticates using JWT token (same as web app). Token obtained by user clicking "Connect" in extension UI.

// Extension includes token in all requests headers: { "Authorization": "Bearer eyJhbGciOiJIUzI1NiIs...", "X-Extension-Version": "1.0.0" }

User Consent

Control Description
Visual Indicator Green border around page when Eliezer is controlling
Disconnect Anytime User can click "Disconnect" to immediately sever connection
Command Preview Show incoming command before execution (optional)
Site Restrictions User can blacklist sensitive sites (banking, email)

Session Management

  • Sessions expire after 1 hour of inactivity
  • User can revoke sessions from web app
  • Extension shows "Last command" timestamp
  • All commands logged for audit

8. API Endpoints

Extension → Server

GET /api/browser/events
SSE stream. Receive commands from Eliezer. Auth required.
POST /api/browser/response
Submit command execution result. Auth required.
POST /api/browser/state
Heartbeat with current browser state. Auth required.

Eliezer → Server

POST /api/browser/send-command
Send command to connected browser. Returns command ID for tracking.
GET /api/browser/sessions
List active browser sessions for current user.
POST /api/browser/disconnect/:sessionId
Force disconnect a browser session.

9. Authentication Flow

Seamless Token Handoff

No copy/paste. One button click connects the extension.

sequenceDiagram actor U as User participant W as Clawchat Web App participant C as Content Script participant E as Extension participant S as Server U->>W: Click "Enable browser control" W->>C: window.postMessage({type: 'PING_EXTENSION'}) alt Extension Installed C->>E: chrome.runtime.sendMessage('PING') E-->>C: {installed: true} C-->>W: postMessage({type: 'EXTENSION_FOUND'}) W->>S: POST /api/extension/token S-->>W: {token: jwt} W->>C: window.postMessage({type: 'CLAWCHAT_AUTH', token: jwt}) C->>E: chrome.runtime.sendMessage({type: 'STORE_TOKEN', token: jwt}) E-->>C: {stored: true} C-->>W: postMessage({type: 'AUTH_SUCCESS'}) W-->>U: Show "Connected ✓" else Extension Not Installed C-->>W: timeout (no response) W-->>U: Show "Install Extension" modal U->>W: Click "Install from Source" W-->>U: Show instructions + download link end

Content Script Bridge

Extension injects content script on clawchat.app to enable cross-origin communication.

// content-bridge.js (runs on clawchat.app) window.addEventListener('message', (event) => { if (event.origin !== 'https://clawchat.app') return; switch (event.data.type) { case 'PING_EXTENSION': chrome.runtime.sendMessage({type: 'PING'}, (response) => { window.postMessage({type: 'EXTENSION_FOUND'}, '*'); }); break; case 'CLAWCHAT_AUTH': chrome.runtime.sendMessage({ type: 'STORE_TOKEN', token: event.data.token }, (response) => { window.postMessage({type: 'AUTH_SUCCESS'}, '*'); }); break; } });

Extension Storage

// background.js chrome.runtime.onMessage.addListener((request, sender, sendResponse) => { if (request.type === 'STORE_TOKEN') { chrome.storage.local.set({ clawchatToken: request.token, connectedAt: Date.now() }, () => { updateBadge('connected'); sendResponse({stored: true}); }); return true; // async response } });

Installation Fallback

When extension is not detected, user sees:

  • Chrome Web Store (when published): One-click install
  • Install from Source: Download zip, load unpacked in chrome://extensions
  • Auto-retry: After installation, page auto-detects extension
